Welcome!
This whole website was made with Friendly Frame, a small static site generator and web framework. Each section below shows one of its features: the result, what was written in edit-me/, and what that got compiled into in actual-website-do-not-edit/.
Reusable elements
Live example
These two author cards are the same reusable element, each given a different picture. The top bar of this page is one too.
Jane Doe
John Smith
Write something once in edit-me/shared/reusables/ (its .scss and .ts get linked automatically), add it to the compilation order below anything it uses, then use it on any page with one tag. {x} becomes the value you give it, [x] a name made from that file name, @template:x another reusable element, and @none: nothing.
You write
edit-me/pages/index/index.html
<r-top-bar title="Friendly Frame" inner=@template:signpost subtitle=@none:> ... <r-author picture="authors.jane_doe.svg"> <r-author picture="authors.john_smith.svg">
edit-me/shared/reusables/top-bar/top-bar.html
<div class="top-bar"> <div class="top-bar-title">{title}</div> <div class="top-bar-subtitle">{subtitle}</div> {inner} </div>
edit-me/shared/reusables/signpost/signpost.html
<div class="signpost"> <a class="signpost-link" href="<root>/en-index.html">English</a> <a class="signpost-link" href="<root>/it-index.html">Italiano</a> </div>
edit-me/shared/reusables/author/author.html
<div class="author"> <img class="author-picture" src="<root>/shared/images/{picture}" alt=""> [picture] </div>
edit-me/shared/reusables-compilation-order.txt
code reusables/signpost reusables/author reusables/top-bar
Compiles into
actual-website-do-not-edit/index.html
<head> ... <link rel="stylesheet" href="shared/reusables/top-bar/top-bar.css"> <link rel="stylesheet" href="shared/reusables/signpost/signpost.css"> <script defer src="shared/reusables/signpost/signpost.js"></script> <link rel="stylesheet" href="shared/reusables/author/author.css"> </head> <body> <div class="top-bar"> <div class="top-bar-title">Friendly Frame</div> <div class="top-bar-subtitle"></div> <div class="signpost"> <a class="signpost-link" href="en-index.html">English</a> <a class="signpost-link" href="it-index.html">Italiano</a> </div> </div> ... <div class="author"> <img class="author-picture" src="shared/images/authors.jane_doe.svg" alt=""> Jane Doe </div> <div class="author"> <img class="author-picture" src="shared/images/authors.john_smith.svg" alt=""> John Smith </div> ... </body>
Reusable typescript
Live example
This year, worked out by index.js in your browser:
In any .ts file, <r-currentYear> is replaced with edit-me/shared/code/currentYear.ts.
You write
edit-me/pages/index/index.ts
<r-currentYear> const year = document.querySelector(".index-year"); if (year) year.textContent = currentYear();
edit-me/shared/code/currentYear.ts
function currentYear(): string { return new Date().getFullYear().toString(); }
Compiles into
actual-website-do-not-edit/index.js
"use strict"; function currentYear() { return new Date().getFullYear().toString(); } const year = document.querySelector(".index-year"); if (year) year.textContent = currentYear();

Adding text
Live example
Switch language: everything except the code changes, and you stay at the same place on the page.
English Italiano
Text goes in edit-me/shared/page_text/, one file per language. Each page gets compiled once per language, and index.html gets the default language (en).
You write
edit-me/pages/index/index.html
<div class="index-title"><div>TEXT=index.welcome</div></div>
edit-me/shared/page_text/en.json
{ "index": { "welcome": "Welcome!", ... }, ... }
edit-me/shared/page_text/it.json
{ "index": { "welcome": "Benvenuto!", ... }, ... }
Compiles into
actual-website-do-not-edit/index.html + en-index.html
<div class="index-title"><div>Welcome!</div></div>
actual-website-do-not-edit/it-index.html
<div class="index-title"><div>Benvenuto!</div></div>
