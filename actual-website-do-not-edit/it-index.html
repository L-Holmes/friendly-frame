Benvenuto!
Questo sito è stato creato interamente con Friendly Frame, un piccolo generatore di siti statici e framework web. Ogni sezione qui sotto mostra una delle sue funzionalità: il risultato, cosa è stato scritto in edit-me/, e in cosa è stato compilato in actual-website-do-not-edit/.

Scrivi qualcosa una sola volta in edit-me/shared/reusables/ (i suoi file .scss e .ts vengono collegati automaticamente), aggiungilo all'ordine di compilazione sotto tutto ciò che usa, poi usalo in qualsiasi pagina con un solo tag. {x} diventa il valore che gli dai, [x] un nome ricavato da quel nome di file, @template:x un altro elemento riutilizzabile, e @none: niente.

Typescript riutilizzabile
Esempio dal vivo
L'anno corrente, calcolato da index.js nel tuo browser:
In qualsiasi file .ts, <r-currentYear> viene sostituito con edit-me/shared/code/currentYear.ts.
Tu scrivi
edit-me/pages/index/index.ts
<r-currentYear> const year = document.querySelector(".index-year"); if (year) year.textContent = currentYear();
edit-me/shared/code/currentYear.ts
function currentYear(): string { return new Date().getFullYear().toString(); }
Viene compilato in
actual-website-do-not-edit/index.js
"use strict"; function currentYear() { return new Date().getFullYear().toString(); } const year = document.querySelector(".index-year"); if (year) year.textContent = currentYear();

Aggiungere testo
Esempio dal vivo
Cambia lingua: cambia tutto tranne il codice, e resti nello stesso punto della pagina.
English Italiano
Il testo va in edit-me/shared/page_text/, un file per lingua. Ogni pagina viene compilata una volta per ogni lingua, e index.html riceve la lingua predefinita (en).
Tu scrivi
edit-me/pages/index/index.html
<div class="index-title"><div>TEXT=index.welcome</div></div>
edit-me/shared/page_text/en.json
{ "index": { "welcome": "Welcome!", ... }, ... }
edit-me/shared/page_text/it.json
{ "index": { "welcome": "Benvenuto!", ... }, ... }
Viene compilato in
actual-website-do-not-edit/index.html + en-index.html
<div class="index-title"><div>Welcome!</div></div>
actual-website-do-not-edit/it-index.html
